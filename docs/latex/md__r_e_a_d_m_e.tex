An Apache 2.\+4.\+x module to deny access by ip address, ip range or user agent.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Description}{Description}}\label{md__r_e_a_d_m_e_autotoc_md1}
This Apache module reads data from a My\+SQL database to check if the incoming request\textquotesingle{}s IP address or user agent is listed in the database as blocked. If a match is found, the module denies access to the requested resource, by sending a 403 response. \textbackslash{} The information about blocked IP addresses, IP ranges, and user agents is loaded to memory from the database at apache server startup for efficient access during request processing. \textbackslash{} Changes to the database (additions or removals of blocked entries) are reflected in the module\textquotesingle{}s in-\/memory data structures by a apache server graceful restart.

{\bfseries{This modules functionality is addes to all virtual hosts and directories of your Apache webserver!}}

This module is designed to help web administrators to protect their servers from unwanted traffic, such as bots, scrapers, or malicious users.\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Compilation instructions}{Compilation instructions}}\label{md__r_e_a_d_m_e_autotoc_md2}

The module expects a My\+SQL/\+\+Maria database with two tables with the following structures:\+
\begin{DoxyItemize}
\item One table for blocked user agents, with a column names value (varchar 255 /\+ text) all other columns are optional.
\item One table for blocked ip addresses, ip ranges and hostnames, with a column names value (varchar 255 /\+ text) all other columns are optional.
\item One table for whitelisted user agents, with a column names value (varchar 255 /\+ text) all other columns are optional.
